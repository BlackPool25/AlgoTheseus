# Support

Need help with AlgoTheseus? Start here so your question lands in the right place.

## Where to ask

- **Usage questions and ideas:** GitHub Discussions (Q&A). Search existing threads first, then open a new one with what you tried and what you expected.
- **Bug reports and feature requests:** GitHub Issues. Include steps to reproduce, expected vs actual behavior, and your environment (OS, Docker version, commit SHA).
- **Security issues:** Do NOT open a public issue. Email `TODO(owner-email)` with details. See `SECURITY.md` for the full policy.

## Response expectations

Support is best effort by volunteers. There is no SLA. Maintainers reply as time allows, and well-written reports with reproductions get attention first.
